# Hero photos: Startup & Innovation page

Drop real ProJenius photos into this folder. No code change is needed;
they appear after the dev server reloads (or the next build).

1. BACKGROUND PHOTO (faded behind the navy hero)
   Name it  backdrop.webp  (or backdrop.jpg / backdrop.png).

2. CARD PHOTOS (the rotating 3-card stack on the right)
   Any other image file here becomes a card. Cards appear in file-name
   order and the file name becomes the caption:

       1-groundnut-machine.webp          ->  "Groundnut machine"
       2-iot-learning-kit.webp           ->  "Iot learning kit"

   Add a small label above the caption with two underscores:

       1-smarter-agriculture__groundnut-machine.webp
           ->  label "Smarter agriculture", caption "Groundnut machine"

   Add at least 3 photos (more is fine, they rotate every 3 seconds).
   Once you add your own card photos, they replace the default ones.

Tips: landscape photos, about 1600 px wide, under ~300 KB (.webp is best).
