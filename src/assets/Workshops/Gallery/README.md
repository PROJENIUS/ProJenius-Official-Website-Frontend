# Workshop Gallery photos

Drop real workshop photos here (.webp, .jpg, .jpeg, .png or .avif). They appear
in the Workshop page gallery automatically, after the photos listed in
src/Components/Learning/Workshops/WorkshopGallery/galleryData.js.

The file name becomes the caption, so name files the way the caption should
read, for example:

    iot-workshop-at-abc-engineering-college.webp  ->  "Iot workshop at abc engineering college"

Keep each photo under about 300 KB (1600 px wide .webp is ideal).
Videos are added in galleryData.js (YouTube links), not in this folder.
